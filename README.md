TROPAR開発方針

現在、TROPARを「掲示板 × SNS × ニュース」のような日本語コミュニティサイトとして開発しています。

まだ開発初期段階なので、実装を進める前にみんながどんなサイトにしたいかを確認したいです！

💬 みんなに聞きたいこと

1. サイト全体

どんなサイトにしたい？

例：

* 掲示板中心
* SNS寄り
* ニュースも充実させたい
* 雑談・交流を重視
* その他

2. スレッド・投稿

どんな機能が欲しい？

例：

* スレッド作成
* コメント・返信
* いいね
* 投稿の編集・削除
* 画像・動画投稿
* 通報
* その他

3. ユーザー機能

どこまで欲しい？

例：

* アカウント
* アイコン
* プロフィール
* フォロー
* 通知
* その他

4. カテゴリ

どんなカテゴリが欲しい？

例：

* 雑談
* ゲーム
* 音楽
* 勉強
* PC・IT
* ニュース
* 質問
* その他

5. デザイン

どんな雰囲気がいい？

例：

* シンプル
* スタイリッシュ
* SNSっぽい
* 掲示板っぽい
* ダーク系
* 明るめ
* その他

※スマホでも見やすく、動作も軽いサイトを目標にします。

6. ルール・ガイドライン

「これはOK」「これはNG」など、必要だと思うルールがあれば書いてください。

7. その他

「こんな機能が欲しい」「こういうサイトにしたい」など自由にどうぞ！

---

📝 回答方法

思いついたものを自由に書いてください。

全部に回答する必要はありません！

集まった意見をもとに、正式な仕様・ガイドラインを決めていきます。
