TROPAR

掲示板 × SNS × ニュースを組み合わせた、日本語コミュニティサイトを開発しています。

TROPARでは、雑談・質問・情報共有・ニュース・趣味など、さまざまなテーマについてユーザー同士が交流できる場所を目指します。

現在は開発初期段階のため、既存のプロトタイプやメンバーの制作物を活かしながら、サイト全体の構成・機能・デザインを整理しています。

---

🎯 開発方針

TROPARでは、以下の両立を目指します。

* シンプルで分かりやすいUI
* スマートフォンでも使いやすい設計
* 軽快で安定した動作
* 掲示板としての使いやすさ
* SNSとしての交流性
* ニュース・情報共有機能
* 将来的な機能追加・拡張のしやすさ

「見た目」だけでなく、**実際に使いやすく、長期的に運用できるサイト**を目指します。

🗂️ 開発構成

現在は既存コードを整理しながら、以下のような構成を目標としています。

```text
src/
├─ components/   # 共通UI・再利用可能な部品
├─ pages/        # 各ページ
│  ├─ index.jsx
│  ├─ medias.jsx
│  └─ new_thread.jsx
├─ services/     # Firebaseとのデータ通信・CRUD
├─ firebase/     # Firebase SDK・設定
└─ hooks/        # Reactカスタムフック
```

バックエンド・データ管理にはFirebaseを中心に使用する予定です。

Firebase

* Firebase Authentication
* Cloud Firestore
* Firebase Hosting
* Cloud Storage

GitHubではソースコードと変更履歴を管理します。

🔧 既存プロトタイプについて

TROPARには、開発メンバーが作成した複数のプロトタイプがあります。

これらは単純に削除するのではなく、実際に使える部分・参考になる部分を確認しながら、新しい構成へ整理・移行します。

例：

`index.jsx` — ホーム画面
`medias.jsx` — ニュース関連画面
`new_thread.jsx` — スレッド作成画面
`script_v2.js` — 掲示板機能のプロトタイプ
HTML/CSS/JavaScriptによる掲示板プロトタイプ

既存コードを参考にしつつ、重複・依存関係・将来的な問題などを確認してから統合します。

---

🛠️ 開発の進め方

大きな機能をいきなり実装するのではなく、

1. 現在のコード・プロトタイプを確認
2. サイト全体の構成を整理
3. データ構造・Firebase構成を設計
4. UI・UXを整理
5. 最小限の機能を実装
6. 動作確認
7. 問題を修正
8. 機能を段階的に追加

という流れで開発します。

設計を確認してから実装することを基本方針とします。
